The key message: these are not two products. It is one agent with the same code and configuration, run in two places. The laptop setup is how we prove it on our own data quickly and cheaply, with no infrastructure. The Azure setup is how we run it as a proper service once we trust it. The Azure lead time is an estimate and mostly depends on approvals, not build work.
