AI Support Agent · 10

In production the agent runs inside our own Azure tenant as a small container. Jira notifies it the moment a ticket is created, passing only the ticket key. Secrets live in Key Vault, every decision is logged to Log Analytics for audit and alerting. Outbound, it calls the Claude API and reads the routing rules from Jira Assets, cached for an hour. It sends no e-mail: vendors are notified by our existing Jira automation. The three controls at the bottom are what the platform and Jira admin teams will set up. For higher volumes we would add a queue in front of the agent; not needed for the pilot.
