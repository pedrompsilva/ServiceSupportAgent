This is the change since the first version. We do not maintain a separate routing table for the agent: it reads the same Service Support schema in Jira Assets that our team already uses, with services, countries, categories, assignment groups and the routing rules. Claude only reads the ticket and names the service and category; both are checked against Assets. The assignment group always comes from the rules. If no rule matches, the agent uses each group's own service and country lists, and if it's still ambiguous a person decides, with the candidate groups listed. The example is a real ticket as our team routed it. Vendors are simply 3rd-party assignment groups; our existing Jira automation notifies them, so the agent sends no e-mail.
