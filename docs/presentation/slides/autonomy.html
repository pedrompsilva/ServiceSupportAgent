AI Support Agent · 11 · Levels are set per ticket type, under one overall cap

This is the governance model. The agent starts at level zero, where it only recommends. Each ticket type, incidents, defects, requests, moves up separately, and only when the evidence meets the bar in the right-hand column. The thresholds are proposals for this group to confirm. Critical tickets always go to a person first regardless of level, and a single setting takes the whole agent back to recommend-only if we ever need it.
